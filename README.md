# PyPID
A PID controller in python with an embedded simulation environment.
- **environment.py**: Represents the physical parameters of a celestial body/environment.
- **system.py**: Enables creation of a system to simulate in an environment
- **pid.py**: Currently used controller
- **simulation.py**: Acts as the dependency injection container. It brings together the System, Environment, 
and Controller, and steps them through time.
